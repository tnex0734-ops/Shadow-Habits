Build a **full-stack WEB APPLICATION** called **"ShadowHabits"** — an anime-themed, AI-assisted habit tracker designed for Gen Z users.

The app must run in the browser and be fully responsive (desktop + mobile).

---

# 🎯 OBJECTIVE

Create a visually immersive habit tracking web app where:
- Users track daily habits
- A character acts as a motivational AI companion
- The entire UI dynamically changes based on selected character
- Character images are fetched dynamically from the web (no static placeholders)
- The experience is smooth, animated, and low cognitive load

---

# 🌐 APPLICATION TYPE

- Web Application (NOT mobile-only)
- Responsive design (mobile-first but works on desktop)

---

# 👥 TARGET USERS

- Gen Z users
- Users with low attention span
- Users who need visual motivation and engagement

---

# 🧱 TECH STACK (STRICT)

Frontend:
- React (Vite)
- Tailwind CSS
- Framer Motion

Backend:
- Node.js + Express

Database:
- MongoDB (Mongoose)

Authentication:
- JWT-based login/signup

Charts:
- Recharts

State:
- React Context API

Image Fetching:
- Use public image APIs (IMPORTANT):
  - Unsplash API OR
  - Google Gemini API (if available) OR
  - Fallback: curated anime image URLs

# 🤖 AI FEATURES (RULE-BASED)

## AI Character Companion

Display character on dashboard:
- Talks to user
- Reacts based on actions

Logic:

IF missed:
→ show gentle nudge

## Smart Habit Setup

---

## Smart Insights
